
# KarthikaMart

## Project Overview
KarthikaMart is a multi-vendor e-commerce shopping application developed as a college capstone project.

## Technologies Used
- C++20
- Drogon Framework
- CMake
- vcpkg
- SQLite
- HTML
- CSS
- JavaScript

## Main Features
- User Registration and Login
- Buyer and Seller Accounts
- Product Management
- Product Search
- Shopping Cart
- Order Management
- Product Reviews and Ratings
- Admin Management
- Mock Payment

## Project Structure
- src: Backend source code
- db: Database files
- frontend: Website files
- test: Testing files

## Project Status
Initial project structure and frontend starter page created.
Backend integration and database configuration are pending.
